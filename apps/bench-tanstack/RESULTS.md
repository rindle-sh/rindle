# Rindle (@rindle/wasm) vs TanStack DB — results

- **Dataset:** scale "large" — 1,000 users, 10,000 issues, 50,000 comments (61,000 rows).
- **TanStack DB:** v0.6.8. **Node:** v22.22.2.
- **Timing:** min of 4 hydrate rounds; min per-pair over 3×25 incremental add+remove pairs.
- Generated by `pnpm --filter @rindle/bench-tanstack bench` (`SCALE=large`). Numbers are machine-specific; re-run locally.

> The **UI views** section is the representative client workload (bounded results). The **full** section materializes whole result sets — engine characterization, not real query shapes.

## Realistic UI views — bounded result

Every result is **bounded to a viewport** (≤ 50 top-level rows) over the same large store — the shape a real client query has ("fetch enough to fill the view"). Only the viewport crosses into JS.

### Hydrate from scratch (ms; lower is better)

| Query | Rindle | TanStack DB | Speedup | Rindle rows | match |
|---|--:|--:|--:|--:|:--:|
| list: newest 50 open | 1.46 | 2.11 | **1.45×** | 50 | ✅ |
| list + author | 1.35 | 8.03 | **5.93×** | 50 (+50) | ✅ |
| list + comment count | 1.49 | 9.90 | **6.64×** | 50 (+250) | ✅ |
| list + 3 recent comments | 1.96 | 7.92 | **4.05×** | 50 (+150) | ✅ |
| issue detail + comments | 0.534 | 7.19 | **13.45×** | 1 (+5) | ✅ |
| list: page 2 | 0.982 | 1.94 | **1.98×** | 50 | ✅ |
